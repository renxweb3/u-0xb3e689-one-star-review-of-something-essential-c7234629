A deadpan one-star review of an everyday essential, the sun: it shows up
uninvited every morning, bleaches everything we own, and customer service
just tells us to wear a hat. A real complaint, filed in earnest, against
a thing that cannot be fixed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). No network, no
randomness: every run writes the same bytes.
